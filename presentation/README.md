# SolarPowerRangers presentation

Open `solarpowerrangers.html` in a browser. Use the arrow keys to change slides and **F** for fullscreen. The slides and their images are embedded in the HTML. The live dashboard link needs an internet connection.

To edit the deck, open `solarpowerrangers.qmd`, then render it with Quarto.

```sh
quarto render solarpowerrangers.qmd
```

`solar.css` controls the theme. The Quarto file includes the diagrams and the chart for the Ontario forecast example.

## Visual assets

`assets/dashboard.png` shows the project dashboard with a November 21, 2026 forecast from the public Cloud Run service. The chart on slide 4 uses the same forecast and selected Ontario cell. `assets/dashboard-qr.png` encodes the same service’s dashboard URL.

The following illustrative photographs were generated with the built-in OpenAI ImageGen tool.
